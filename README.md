# CareerCraft Studio

> **Dynamic Career Portal & ATS Resume Engineering Studio**

Full-stack career acceleration platform and dynamic resume engineering studio. Built with Next.js, Prisma, and Supabase featuring customer/admin management, ATS-tailored resume generation, and hiring application trackers.

## ✨ Key Features

- **Autonomous Intelligence:** Powered by high-speed LLM reasoning and real-time inference pipelines.
- **Modern Responsive UI:** Polished interface featuring responsive layouts, fluid transitions, and clear visual hierarchy.
- **Enterprise-Grade Security:** Strict environment separation, sanitized API configuration, and secure session handling.

## 🛠️ Getting Started

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/Rhythm2903/CareerCraft-Studio.git
cd CareerCraft-Studio

# Install dependencies
npm install
```

### 2. Configure Environment Variables

```bash
cp .env.example .env.local
```

Populate `.env.local` with your database and API keys.

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
